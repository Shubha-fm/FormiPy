# SoftwareX Phase 4: varied synthetic benchmark structures

The study compares **12 hand-designed synthetic structures** using 24 reference/mutant models:
- Six different state-machine topologies: chain, fork, retry loop, fallback, pipeline, and cycle.
- Six actor/use-case permission patterns: single owner, role hierarchy, separation of duties, departments, maintenance and multi-tenancy.

Each reference meets its stated finite safety invariant, and each mutant deliberately changes an edge or permission association to violate that invariant. The CI workflow invokes the real TLC model checker and the *default FormiPy-generated* pytest suite independently, then archives complete inputs, TLC results, Python test logs and CSV outcomes.

This experiment is not based on industrial UML datasets. It does not evaluate complete UML semantics or establish Python/TLA+ equivalence. The state-machine examples isolate a hazard-at-unsafe property, while use-case examples isolate forbidden-request permissions. They have different fault operators. The default generated pytest checks may not cover the same properties, so comparisons must be described as **coverage differences**, not matched-oracle accuracy.

Run with Python 3.12, Java 17 and the official TLC JAR:

```bash
python -m pip install -r backend/requirements-dev.txt
python backend/install_tlc.py
PYTHONPATH=backend python scripts/run_softwarex_phase4_2026.py
```
